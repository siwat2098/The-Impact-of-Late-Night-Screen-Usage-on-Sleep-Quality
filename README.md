# The-Impact-of-Late-Night-Screen-Usage-on-Sleep-Quality
เว็บไซต์ในการเผยแพร่ข้อมูลประสิทธิภาพการนอนเปรียบเทียบระหว่างการใช้หน้าจอในตอนกลางคืนกับไม่ใช้
โดยสามาารถนำเสนอข้อมูลได้ดังนี้
KPI ทั้ง 4 ตัวบอกว่าปัญหาการนอนในกลุ่มตัวอย่างนี้มีอยู่จริง ก่อนที่กราฟถัดไปจะอธิบายว่าอะไรเกี่ยวข้องกับปัญหานี้ นักเรียนนักศึกษา 4,500 คนนอนเฉลี่ยเพียง 6.70 ชั่วโมงต่อคืน ซึ่งต่ำกว่าช่วง 8–10 ชั่วโมงที่แนะนำสำหรับวัยรุ่น และให้คะแนนคุณภาพการนอนเฉลี่ยเพียง 2.47 จาก 5
Total Students (4,500 คน): ขนาดตัวอย่างทั้งหมด เมื่อกรองข้อมูลตัวเลขนี้จะลดลง ทำให้รู้ว่ากลุ่มที่กำลังดูมีกี่คน
% Late-Night Users (58.8%): 2,644 คนใช้หน้าจอตอนกลางคืน ซึ่งเกินครึ่งหนึ่งของกลุ่มตัวอย่าง
Average Sleep Duration (6.70 ชม.): ค่าเฉลี่ยรวมต่ำกว่าที่แนะนำ
Average Sleep Quality (2.47/5): อยู่ต่ำกว่ากึ่งกลางของสเกล คุณภาพการนอนโดยรวมค่อนไปทางไม่ดี
กราฟที่ 1: Pie สัดส่วนผู้ใช้หน้าจอตอนกลางคืน
กราฟนี้ตอบว่าพฤติกรรมการใช้หน้าจอตอนกลางคืนพบได้มากแค่ไหน ผู้ใช้ตอนกลางคืนมี 58.8% ส่วนที่ไม่ใช้มี 41.2% 
กราฟนี้ให้บริบทเรื่องขนาดของแต่ละกลุ่มก่อนจะนำไปเทียบค่าเฉลี่ยในกราฟที่ 2
พฤติกรรมนี้เป็นเรื่องที่พบได้ทั่วไป ไม่ใช่กลุ่มเล็ก ๆ
เมื่อกรองตามเพศ อายุ หรืออุปกรณ์ จะเห็นว่ากลุ่มไหนใช้ตอนกลางคืนมากกว่ากัน
กราฟที่ 2: Bar Late-Night Usage → Average Sleep Quality
กราฟนี้ตอบคำถามหลักของ dashboard ว่าคนที่ใช้หน้าจอตอนกลางคืนมีคุณภาพการนอนต่ำกว่าคนที่ไม่ใช้หรือไม่ คำตอบคือต่ำกว่าจริง 
และเมื่อดูร่วมกับกราฟที่ 1 จะเห็นว่ากลุ่มที่คะแนนต่ำกว่าเป็นกลุ่มใหญ่กว่า ผลกระทบจึงครอบคลุมคนส่วนใหญ่
กลุ่มใช้ตอนกลางคืนได้ 2.24 คะแนน
กลุ่มไม่ใช้ได้ 2.81 คะแนน
ต่างกัน 0.57 คะแนน หรือประมาณ 20%
กราฟที่ 3: Line Daily Usage Hours → Average Sleep Duration
กราฟนี้ตอบว่าใช้หน้าจอนานขึ้นแล้วนอนน้อยลงหรือไม่ ผลคือชั่วโมงนอนเฉลี่ยลดลงต่อเนื่องเป็นขั้นบันได 
กราฟเส้นเห็นรูปแบบชัดกว่า scatter เพราะเฉลี่ยเป็นช่วงละ 1 ชั่วโมงแล้ว และแถบสีจางช่วยบอกความไม่แน่นอนของแต่ละช่วง
ใช้ 1–2 ชม./วัน นอนเฉลี่ยราว 8.0 ชม. แต่ใช้ 14 ชม./วัน เหลือราว 4.1 ชม.
ความสัมพันธ์เชิงลบค่อนข้างแรง (r ≈ −0.72)
ปลายขวาของกราฟมีแถบกว้างขึ้น เพราะช่วงที่ใช้นานมากมีคนน้อย ค่าเฉลี่ยจึงไม่นิ่งเท่าช่วงอื่น
ช่วง 5–7 ชม./วัน ชั่วโมงนอนเฉลี่ยเริ่มต่ำกว่าค่าเฉลี่ยรวม ที่ราว 6–6.6 ชม.
กราฟที่ 4: Scatter Daily Usage Hours → Sleep Quality
กราฟนี้ตอบว่าใช้หน้าจอนานขึ้นแล้วคุณภาพการนอนลดลงหรือไม่ ผลคือลดลงชัดเจน และให้ข้อสรุปตรงกับกราฟที่ 3 ว่ายิ่งใช้นาน 
ทั้งนอนสั้นลงและนอนหลับไม่ดีขึ้น เส้นแนวโน้มแยกสองกลุ่มช่วยดูว่าชั่วโมงใช้งานกับการใช้ตอนกลางคืนมีผลแยกกันหรือไม่
ความสัมพันธ์เชิงลบ (r ≈ −0.68)
จุดสีม่วง (ใช้ตอนกลางคืน) กระจุกอยู่ฝั่งคะแนนต่ำ ส่วนจุดสีเขียว (ไม่ใช้) อยู่สูงกว่า
คะแนนเป็นจำนวนเต็ม 1–5 จึงสุ่มกระจายจุดแนวตั้งเล็กน้อยเพื่อให้เห็นความหนาแน่น
กราฟที่ 5: Pie สัดส่วนประเภท Device
กราฟนี้ตอบว่านักเรียนนักศึกษาใช้อุปกรณ์ประเภทใดมากที่สุด สมาร์ตโฟนครองสัดส่วนเกือบทั้งหมด จึงเป็นอุปกรณ์หลักที่ควรสนใจเมื่อพูดถึงการแก้ปัญหา 
และเมื่อคลิกเลือกอุปกรณ์ กราฟ 1–4 จะเปลี่ยนตาม ทำให้ใช้เปรียบเทียบว่าอุปกรณ์แต่ละกลุ่มมีรูปแบบต่างจากภาพรวมหรือไม่
Smartphone 83.9%, Laptop/PC 13.2%, Tablet 2.9%
กลุ่ม Tablet มีเพียง 129 คน ถ้ากรองลงลึกตัวอย่างจะน้อยเกินไปและค่าที่ได้ไม่เสถียร
